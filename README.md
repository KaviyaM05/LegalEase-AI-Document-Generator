LegalEase – AI Legal Document Generator

LegalEase is a simple web-based legal document generator that helps users create basic legal document drafts quickly and easily.

🚀 Live Demo

https://kaviyam05.github.io/LegalEase-AI-Document-Generator/

📌 Features

- Simple and user-friendly interface
- Generate legal document drafts
- Four document types supported:
  - Rental Agreement
  - Leave & License Agreement
  - Affidavit
  - Legal Notice
- Form-based document generation
- Print / Save generated documents as PDF
- Responsive and clean design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- GitHub Pages

📄 Documents Supported

1. Rental Agreement

Users can enter tenant, landlord, property, rent, rental period and security deposit details.

2. Leave & License Agreement

Users can enter licensor, licensee, property, license period and license fee details.

3. Affidavit

Users can enter declarant, address, purpose and statement details.

4. Legal Notice

Users can enter sender, receiver, address, subject and notice details.

⚠️ Disclaimer

This application generates draft documents for educational and informational purposes only. The generated documents should be reviewed by a qualified legal professional before actual use.
